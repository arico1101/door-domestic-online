# トビラ 国内版 オンライン

各自の端末で遊ぶ、教育すごろく「トビラ 国内版」のオンライン版。
16歳から45歳までの29年間をたどり、日本の中でも「生まれた家庭」によって見えている選択肢がちがうことを体験する。

```bash
npm install
npx wrangler dev       # http://localhost:8787
```

**公開URL（`main` にマージすると自動で反映）： https://tobira-domestic.tobira-online.workers.dev**

## どう作ったか

- **しくみ**は、せかい版オンライン（`door-world-online`）をそのまま使っている。
  Cloudflare Workers ＋ Durable Objects（1ルーム＝1オブジェクト）。判定はすべてサーバーで行い、
  画面は表示と入力だけ。ロビー・あいことば・進行役メニュー・再接続・ネタバラシ・トビラ一覧も同じ
- **ルールと文言**は、国内版1画面（`door-domestic-game`）にそろえてある。
  盤面36マス・家庭カード6種・トビラ・できごと・エンディング・あそびかたは、1画面版と同じ中身
- 書き出す名前（`choiceDef`・`MODES` など）をせかい版とそろえてあるので、
  せかい版オンラインの直し（画面・進行役の操作など）は、ほぼそのまま持ってこられる

### せかい版オンラインとのちがい

| | せかい版オンライン | 国内版オンライン |
| --- | --- | --- |
| 年齢・盤面 | 6〜35歳（36マス）／6〜25歳（24マス）を選ぶ | 16〜45歳（36マス）の1つだけ。選ぶ欄は出さない |
| 人数 | 2〜6人／1〜4人 | 1〜6人 |
| お給料 | 基本給＋★×掛け率（生まれた場所で差） | 全員「20万＋★×10万＋仕送り」 |
| 家庭カードで見せるもの | 物語・朝・1日の暮らしのお金 | 物語・まち・仕送り |
| 必ず配る家庭 | ウガンダの遺児家庭を必ず1枚 | なし（ただ混ぜて配る。1画面版と同じ） |
| 奨学金 | ぜんぶ版は35歳で清算 | 45歳のゴールで清算 |
| 言語 | 日本語／英語 | 日本語だけ（切りかえボタンは出さない） |
| 結果画面 | ふりかえりは進行スライドで | 1画面版の「ふりかえりタイム」を結果画面に出す |

### 守るべき条件（せかい版と同じ）

1. **秘密を削らない。** 家庭カードの境遇（物語・まち・仕送り）はみんなに見せるが、
   「とくい」と見えない選択肢のタグは結果発表まで本人だけ（`publicCard()` と `test/ops.mjs`）
2. 選択肢とその状態は、手番の人にだけ送る。ほかの人にはトビラの名前だけ
3. **ゲームの中身は1画面版と同じに保つ。** 文言や数字を変えるときは、`door-domestic-game` も一緒に直す

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `src/index.js` | Worker + Room（Durable Object）。ゲーム進行の全判定 |
| `public/rules.js` | サーバーと画面が共有するルール・文言・盤面データ（国内版の中身はここ） |
| `public/app.js` | クライアント（表示と入力のみ） |
| `public/se.js` | 効果音（WebAudioでその場で組み立てる） |
| `public/index.html` | 画面の骨格とCSS |
| `public/chars/` | キャラの絵（p1〜p4。p5・p6 は仮の絵で、5人目からだけ使う） |
| `test/domestic.mjs` | **国内版だけのテスト**（ルールと、6人で最後まで遊ぶ通し） |
| `test/play.mjs` | 通しプレイの自動テスト（人数を変えて流す） |
| `test/ops.mjs` | 進行役むけ操作と、選択肢・とくいの秘匿のテスト |
| `.github/workflows/` | `main` → 公開URLへ自動デプロイ／PRごとのプレビューURL |

## テスト

`npx wrangler dev` を起動したうえで：

```bash
npm test
# または個別に
node test/domestic.mjs
node test/ops.mjs
for n in 1 2 4 6; do N=$n node test/play.mjs; done
```

## デプロイ

`main` に入った変更は GitHub Actions（`.github/workflows/deploy.yml`）が公開URLへ反映する。
PRを作ると、PRごとのプレビューURL（`tobira-domestic-pr-<番号>`）がコメントで出る。

**どちらも、このリポジトリの Secrets に `CLOUDFLARE_API_TOKEN` と `CLOUDFLARE_ACCOUNT_ID` が要る**
（せかい版オンラインと同じ値でよい）。Worker の名前は `tobira-domestic` なので、せかい版を上書きすることはない。

## まだないもの

- 進行スライド・あそびかたの冊子（1画面版の `slides.html`・`rules.html` は1台を囲む前提の説明）
- Storybook（せかい版にはある。必要になったら、せかい版の `storybook/` を国内版の家庭カードに合わせて持ってくる）
